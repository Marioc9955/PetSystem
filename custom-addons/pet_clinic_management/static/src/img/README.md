# Landing page artwork

`pets-hero.png` is original artwork generated with the built-in imagegen tool on
2026-09-15. It is a transparent RGBA PNG, 1254 × 1254 pixels. The installed starter
page stores its own editable copy in the database; the split block uses this file
as its decorative fallback when no custom image is supplied.

Prompt:

> Use case: photorealistic-natural. Asset type: veterinary clinic website hero cutout. Create an original high-quality studio portrait of two funny lovable pets together: a happy golden-brown and white beagle with floppy ears, open mouth and a charming tilted head, alongside a smaller curious ginger tabby cat with wide eyes. Both face the viewer. Show their heads and upper bodies, paws at the bottom, comfortably framed with all ears visible. Soft natural studio light, believable detailed fur, friendly playful expressions, premium editorial pet photography. Isolated on a genuinely transparent background with clean alpha edges, no background scene or shadow rectangle. Square composition for placement on a pale blue website hero. No text, no logos, no collars with text, no watermark.

Design direction: pale blue surfaces, expressive pets, rounded service cards,
and spacious typography inspired by [Ekaterina Muraveva’s veterinary landing page](https://www.behance.net/gallery/105361229/Landing-page-Veterinary-clinic).
No images were copied from that project.
